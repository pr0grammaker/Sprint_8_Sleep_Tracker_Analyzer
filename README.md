# 💤 Sleep Tracker Analyzer

## 📌 Описание проекта

**Sleep Tracker Analyzer** — это приложение для анализа сна пользователя на основе данных, полученных с умных часов.

Проект помогает пользователю:

- 📊 анализировать продолжительность сна
- 🌙 выявлять бессонные ночи
- 🧠 определять хронотип пользователя
- 📈 оценивать качество сна
- 🔍 находить потенциальные проблемы режима

Цель приложения — предоставить пользователю **понятную аналитику** и помочь сформировать более здоровые привычки сна.

---

## 📝 Постановка задачи

Многие люди хотят выработать правильные привычки сна. Однако объективно оценить:

- во сколько они ложатся
- сколько часов спят
- насколько качественным был сон

часто оказывается сложной задачей.

Предполагается, что пользователь использует **умные часы**, которые автоматически фиксируют:

- время засыпания
- время пробуждения
- качество сна

Эти данные объединяются в **сессии сна**.  
В большинстве случаев одна сессия соответствует одной ночи, однако возможны:

- дневные сессии сна
- прерывистый сон
- нестандартные временные интервалы

---

## 📂 Формат входных данных

Приложение принимает файл лога сна в формате:
дата_засыпания;дата_пробуждения;качество

Пример:

01.10.25 22:15;02.10.25 08:00;GOOD

02.10.25 23:00;03.10.25 08:00;NORMAL

03.10.25 14:30;03.10.25 15:20;NORMAL

03.10.25 23:30;04.10.25 06:20;BAD


Возможные значения качества сна:

- **GOOD** — хороший сон
- **NORMAL** — нормальный сон
- **BAD** — плохой сон

Записи в файле упорядочены по дате и времени.

## ⚙ Архитектура приложения

Приложение построено с упором на **расширяемость**.

Каждая аналитическая функция:

- реализуется как отдельный класс
- принимает список `SleepingSession`
- возвращает `SleepAnalysisResult`
- реализует интерфейс `Function<List<SleepingSession>, SleepAnalysisResult>`

Это позволяет:

- легко добавлять новые аналитические функции
- не изменять основной код приложения
- соблюдать принцип Open/Closed (SOLID)

---

## 📊 Реализованные аналитические функции

Пример набора аналитики:

- 💤 Количество бессонных ночей
- ⏱ Средняя продолжительность сна
- 📉 Количество коротких сессий сна
- 🌙 Определение хронотипа (Сова / Жаворонок / Голубь)
- 📈 Анализ качества сна

---

## 🧠 Определение хронотипа

Пользователь классифицируется по хронотипу:

- 🦉 **Сова** — засыпает после 23:00 и просыпается после 09:00
- 🐦 **Жаворонок** — засыпает до 22:00 и просыпается до 07:00
- 🕊 **Голубь** — все остальные случаи

При равенстве типов пользователь считается «Голубем».  
Дневные сессии сна и бессонные ночи в расчёт не принимаются.

---

## 🚀 Расширяемость

Для добавления новой аналитической функции необходимо:

1. Создать новый класс
2. Реализовать интерфейс `Function<List<SleepingSession>, SleepAnalysisResult>`
3. Реализовать метод `apply`

Никаких изменений в существующем коде не требуется.
